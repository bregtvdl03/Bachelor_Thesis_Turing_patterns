The reaction function $f$ in \cref{eq:schnakenberg_reactions} includes natural decay of the species $u$. As it is relevant for the models we consider in \cref{ch:Bulk_surface_model,ch:Numerical_Analysis}, we show that the addition of decay of $v$ in the function $g$ does not cause the model to lose its ability to generate Turing patterns. To this end, we consider the kinetics
%
\begin{equation}
    f(u, v) = a - u + u^2 v \qquad \text{and} \qquad g(u, v) = b - \delta_v v - u^2 v,
\end{equation}

\noindent
where $\delta_v > 0$ is the decay rate for $v$. The new uniform steady states are $U$ and $V$ with $U$ being a positive real root of
%
\begin{equation*}
    U^3 - (a + b)U^2 + \delta_v U - a \delta_v = 0,
\end{equation*}

\noindent
if such a root exists, and
%
\begin{equation*}
    V := \frac{b}{U^2 + \delta_v}.
\end{equation*}

\noindent
One can check that if $\delta_v = 0$, we recover the uniform steady states from the classical Schnakenberg equations, given in \cref{eq:schnakenberg_steadystates}. When we use these new kinetics in the model of \cref{eq:reac_diff} with the new parameter $\delta_v$ set to $0.1$, we see from the simulations in \cref{fig:schnak_dec_1-3,fig:schnakenberg_frames_4-6} that this model is also able to generate Turing patterns. In this simulation, the other parameters are set to the same values as before, i.e. $d = 50$, $a = 0.1$, $b = 0.9$ and $\gamma = 12$. The domain is $\Omega = (-8, 8)^2$ again, and the initial conditions are set to a random perturbation around the uniform steady states as in \cref{eq:schnakenberg_initial}. With this relatively low value of $\delta_v$, we see that this model generates patterns that are similar to the ones generated by the classical Schnakenberg equations in both shape and scale.
